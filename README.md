# Pre-Commitment Impact & Risk Prediction for Self-Evolving Multi-Agent Workflows

Capstone project PW_25_VSH_01 (guide: Vidyashankar H).

Self-evolving agent systems can change their Model, Memory, Tools or Workflow. A change that
improves one metric can hurt cost, latency, reliability or safety, and today developers find out
only after the change is applied. This project adds a **pre-commitment layer** that, using
historical run data, will predict the impact (Quality, Cost, Latency, Reliability) and risk
(Regression, Failure, Cascade, Safety alignment drift) of a proposed change and output
ACCEPT / MODIFY / REJECT with a reason and a suggested mitigation.
A Common Adapter Interface keeps the core framework-independent. EvoAgentX is the first system under test.

## Files

- `schema.py` - common representation: `TelemetryRecord`, `EvolutionChange`, `OutcomeLabel`, `Decision`, `CommonAdapter`, `EvoAgentXAdapter`
- `features.py` - prototype feature extraction on the common representation
- `decision.py` - rule-based ACCEPT / MODIFY / REJECT skeleton (placeholder thresholds, not calibrated)
- `demo.py` - end-to-end demo of everything implemented so far
- `run_logger.py` - runs the workflow N times and logs one JSON line per run
- `sequential_workflow_gemini.py` - 2-agent (Planning, Coding) EvoAgentX workflow on Gemini
- `data/run_log_sample.jsonl` - telemetry from the 3 real runs
- `data/run_features.csv` - features generated by `demo.py`
- `docs/architecture.md`, `docs/requirements.md` - draft architecture and requirements
- `PROGRESS.md` - status tracker

## Setup

1. Clone and install EvoAgentX (https://github.com/EvoAgentX/EvoAgentX) in a venv: `pip install -r requirements.txt`, then `pip install -e .`
2. Pin these versions (newer ones break EvoAgentX): `pip install "mcp==1.30.0" "fastmcp==2.14.7"`
3. Create a `.env` file with `GEMINI_API_KEY=your_key` (never commit this file).

## Run

```
python demo.py                      # demo on the sample log (no API key, standard library only)
python schema.py                    # load and validate the log through the adapter
python run_logger.py 1              # real run: needs the EvoAgentX venv and a Gemini key
```
